# MetaExtract

A Manifest V3 browser extension, still in planning, that saves the video
playing on any page, including Facebook and Instagram, as a single MP4 with a
metadata sidecar. Everything runs locally in the browser.

See [docs/PLAN.md](docs/PLAN.md) for the review of existing video capture
extensions, the architecture and the phased build plan.

Planned distribution: a GitHub release zip loaded through
`chrome://extensions` → Developer mode → Load unpacked. Chrome only.
